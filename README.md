## 🌸 About me

I started in infrastructure, administering Linux and Windows servers for companies such as PT Lion Super Indo and PT Inovasi Informatika Indonesia. That work taught me why data has to be accurate, consistent, and available. Today I build the pipelines and analyses on top of that foundation, from raw data to dashboards, with quality checks along the way.

- 📊 Data Analyst / Data Engineer, based in Indonesia
- 🎓 B.Sc. Information Systems, Telkom University (GPA 3.64 / 4.00)
- 🚀 Graduate of the Hacktiv8 Data Science Bootcamp
- 🌱 Currently learning: dbt, cloud data warehouses (BigQuery / Snowflake), Spark &amp; Kafka, Power BI, advanced SQL, and MLOps / LLM basics
